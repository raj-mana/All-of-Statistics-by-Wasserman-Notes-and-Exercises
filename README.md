# Notes and Exercises for *All of Statistics* by Larry Wasserman

These are personal notes and exercise solutions for *All of Statistics* by Larry Wasserman, which covers many of the main ideas in modern statistics. This repository currently contains Jupyter notebooks for the following chapters:
1.  Probability
2.  Random Variables
3.  Expectation
4.  Inequalities
5.  Convergence of Random Variables
6.  Models, Statistical Inference, and Learning
7.  Estimating the CDF and Statistical Functionals
